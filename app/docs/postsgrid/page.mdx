# Posts Grid

The `PostsGrid` is a wrapper component designed to render multiple posts at once using [PostCard](/docs/postcard).  
It’s not meant for displaying a single article, but for organizing collections of posts in different layouts.

Common use cases include:

- Blog homepages
- Category/archive pages
- Search results
- Infinite scrolling feeds

A **PostList** arranges posts in a vertical feed, while a **PostGrid** lays them out in a grid format.  
Both handle looping through post data and can manage extras like pagination, tags, or “load more” functionality.

### Notes on `customClassNames`

You can override styling by passing a `customClassNames` object with the following keys:

- `wrapper` → outer container wrapping the entire component
- `headerWrapper` → wrapper around title + description section
- `title` → section title styling
- `description` → section description styling
- `gridWrapper` → container for grid or list layout
- `paginationWrapper` → wrapper for pagination controls
- `tagsWrapper` → container for tags section
- `tagButton` → styling for each tag button
